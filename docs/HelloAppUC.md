# UC1 - Display Hello World

## Description
The application displays the message "Hello World" on the console.

## Disadvantages of Previous Use Case
None. This is the first use case.

## Preconditions
- Java JDK is installed.
- Maven project is created.
- HelloApp.java exists.

## Main Flow
1. Start the application.
2. Execute the main() method.
3. Display "Hello World".
4. Exit.

## Post Conditions
The message "Hello World" is displayed successfully.

## Hints
- Use System.out.println().
- The main() method is the entry point of every Java application.

## Code Snippet

```java
public class HelloApp {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
```

## Expected Output

```
Hello World
```

## Concepts Learned

- Java Program Structure
- main() Method
- Console Output
- System.out.println()
